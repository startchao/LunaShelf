# 0.6.3 聽書修復：iPhone PWA 驗收

此版本保留網頁語音。鎖屏／背景時暫停，回到 App 由使用者點播放；未新增持續背景音訊。移除靜音音軌，鎖屏／耳機媒體控制也不再以假音軌呈現。

## 已改動

- 以書籍 ID 儲存段落及 260 字以內的分段位置，與閱讀頁面分開。
- 啟動後五秒未收到 onstart 即取消卡住的引擎，恢復可操作狀態；不相信 pending/speaking 能代表已發聲。
- 錯誤保留失敗片段；舊事件不能推进新的播放。
- 語速範圍 0.5–4，保留既有偏好。試聽同一段文字並列出聲線、參數與事件計時秒數；這不是聲學精確測量。
- 回到前景及每段開始前檢查睡眠期限。手動停止／選章／翻頁會清除聽書位置，返回書庫則保留。

## 實機驗收（尚待執行）

1. 匯入含 600 字以上單一段落的 TXT，播放至第二分段，切換 App 30 秒後回來；點播放應重念中斷分段，不回到整段起點、不漏段。
2. 鎖屏 30 秒、5 分鐘後重複；強制關閉再開啟 PWA 並開同一本書，位置仍應保留。
3. 暫停／播放快速交替五次，再測來電、Siri、AirPods 斷線與重連。記錄無聲時的提示與恢復結果。
4. 設定相同聲線，以 1、2、2.5、3、4 分別點「測試目前語速」，記下秒數。換聲線及升級 Beta 後重測。試聽不應改動小說位置。
5. 睡眠期限在背景經過後返回，應顯示暫停，不能自動播放。
6. 兩本書交替、選章、翻頁與進度條跳轉，確認不會跳回舊聽書位置。

## 驗證限制

Node 測試使用模擬語音事件，不能證明 iOS 引擎／藍牙行為。若引擎發送 onstart 後仍無聲，網頁無法可靠判斷是否有實際音訊；可手動暫停重試。套件下載受目前環境限制，完整 Vite 建置需在正常開發環境執行 npm ci、npm run check、npm run build。

## 後續開發

真正背景聽書與獨立倍速需新增音訊生成／快取／播放層，或 iOS 原生語音與音訊層。此修復不新增雲端 TTS 費用或上傳書籍內容。
